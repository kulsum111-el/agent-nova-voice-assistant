# Agent Nova – Python Voice Assistant

Agent Nova is a Python-based desktop voice assistant with a graphical user interface. It supports text input, text-to-speech, speech recognition, and basic commands.

## Features
- Interactive desktop GUI built with Tkinter
- Text-to-speech responses
- Speech-to-text using microphone input
- Greeting, date, and time responses
- Open Google and YouTube
- Search Google using text commands
- Clear chat messages

## Technologies Used
- Python
- Tkinter
- pyttsx3
- SpeechRecognition
- PyAudio
- Threading

## Installation and Setup

1. Install Python.
2. Download or clone this repository.
3. Install the required libraries:

   `pip install -r requirements.txt`

4. Run the application:

   `python voice_assistant.py`
